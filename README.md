# Сайт Ксении Савкиной

Личный сайт: статичный HTML, CSS и немного JavaScript, без сборки и фреймворков.
Хостинг на [Amvera](https://amvera.ru): Docker-образ с nginx.

## Хостинг на Amvera

Что лежит в репозитории:

- `amvera.yml` — настройки для Amvera: собирать по `Dockerfile`, сайт слушает порт 80.
- `Dockerfile` — образ на `nginx:stable-alpine`, в него копируются `index.html`, `assets/`, `media/` и `files/`.
- `deploy/nginx.conf` — nginx: сжатие, кеширование, поддержка перемотки видео, несуществующие адреса ведут на главную.

### Первый запуск

1. В Amvera создай проект с загрузкой кода через git. Конфигурацию в интерфейсе не задавай:
   `amvera.yml` уже в репозитории, а правка в интерфейсе создаёт отдельный коммит, который потом придётся подтягивать.
2. Подключи код одним из способов.
   - **Через GitHub, с автообновлением.** Вкладка «Репозиторий» → GitHub: токен, репозиторий
     `izumvania-gif/kseniasavkinacv`, ветка `main`. Потом добавь вебхук в GitHub
     (**Settings** → **Webhooks**) с адресом и секретом из Amvera, тип `application/json`, событие **Push**.
     После этого каждый пуш в `main` пересобирает сайт.
   - **Вручную через git.** Адрес репозитория есть на вкладке «Репозиторий»:
     ```
     git remote add amvera https://git.amvera.ru/<ник>/<проект>
     git push amvera main:master
     ```
     Amvera собирает только ветку `master`, поэтому `main:master`. Логин и пароль от аккаунта Amvera.
3. Сборка начнётся сама, ход видно во вкладке «Лог сборки».
4. «Настройки» → «Доменные имена» → «Добавить доменное имя»: бесплатный `<проект>.<ник>.amvera.io` с HTTPS
   или свой домен.

### Обновление

- С вебхуком: пуш в `main`.
- Вручную: `git push amvera main:master`.

HTML, стили и скрипты браузер сверяет с сервером при каждом заходе, поэтому правки видны сразу.
Фото и видео кешируются на сутки, шрифты на 30 дней: если заменить видео файлом с тем же именем,
вернувшийся посетитель может видеть старое до суток.

### Проверить образ у себя

```
docker build -t ksenia-site .
docker run --rm -p 8080:80 ksenia-site
```

Сайт откроется на http://localhost:8080.

## Запасной вариант: GitHub Pages

Сайт работает и без сервера. **Settings** → **Pages** → **Deploy from a branch**, ветка **main**, папка **/ (root)**.
Адрес: https://izumvania-gif.github.io/kseniasavkinacv/

## Видео

В разделе «Вино» два вертикальных видео рядом, подписи под ними. Видео играют без звука по кругу,
пока блок на экране; в верхнем углу кнопки звука и паузы (внизу кадра у видео свои субтитры).

- **Сорта винограда:** `media/grapes.webm` и `media/grapes.mp4`, обложка `assets/img/grapes-poster.jpg`.
- **Приорат:** `media/priorat.webm` и `media/priorat.mp4`, обложка `assets/img/priorat-poster.jpg`. Водяной знак обрезан.

Каждое видео лежит в двух форматах, браузер берёт подходящий. Чтобы заменить видео,
положи новые файлы с теми же именами (лучше сжать до 5–10 МБ, H.264 для MP4).

## Как заменить видео в «Обо мне» или резюме

- Видео в «Обо мне»: `media/ksenia.webm` и `media/ksenia.mp4` (одно видео в двух форматах, без звука),
  обложка `assets/img/ksenia-poster.jpg`. Видео играет по кругу, пока блок на экране, кнопкой ставится пауза.
- Резюме: `files/Kseniia_Savkina_CV.pdf`.

## Как устроен сайт

- **Первый экран.** Тёмная сцена с бутылкой шампанского: пробка-«грибок» с мюзле и пластинкой, фольга до венчика,
  кольеретка на горлышке. При прокрутке бутылка дрожит, пробка вылетает вместе с мюзле,
  брызги бежевого цвета заливают экран светлым, а следующий блок уже того же цвета.
  Брызги рисуются в `assets/js/main.js`, без картинок.
- **Пузырьки** мелкие и нечастые, поднимаются по краям экрана.
- **Проекты** карточками по четыре в ряд, FMCG первыми. Карточка наклоняется за курсором, по нажатию
  переворачивается в ту сторону, где нажали; на обороте итог и история. Каждый проект — блок `<li class="card">`.
- **Контакты** прямо внутри бокалов: вино наливается, и почта, телефон и Instagram проступают в нём.
  Почту и телефон можно скопировать кнопкой.

Если в настройках устройства включено «Уменьшить движение», анимации выключаются: бутылка стоит закрытой,
бокалы уже налиты, контакты видны сразу. Без JavaScript у карточек видны обе стороны.
