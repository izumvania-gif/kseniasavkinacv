# Сайт Ксении Савкиной

Личный сайт: статичный HTML, CSS и немного JavaScript, без сборки и фреймворков.
Публикуется через GitHub Pages из ветки `main`.

Адрес после включения Pages: https://izumvania-gif.github.io/kseniasavkinacv/

## Как включить GitHub Pages (один раз)

1. Открой репозиторий на GitHub → **Settings** → **Pages**.
2. В блоке **Build and deployment** выбери **Source: Deploy from a branch**.
3. Ветка **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты сайт появится по адресу выше.

## Как добавить видео

В блоке «Вино» два больших блока, видео в них играет фоном: без звука, по кругу, пока блок на экране.
Поверх видео остаются заголовок и две кнопки: включить звук и поставить на паузу.

1. Положи файлы в папку `media/`, например `media/grapes.mp4` и `media/priorat.mp4`.
   GitHub принимает файлы до 100 МБ; лучше сжать ролик до 20–40 МБ (H.264).
2. В `index.html` найди `<article class="vblock ..." data-src="" ...>` и впиши путь:
   - первый блок (сорта винограда): `data-src="media/grapes.mp4"`
   - второй блок (Приорат): `data-src="media/priorat.mp4"`
3. По желанию добавь обложку: картинку в `media/` и путь в `data-poster`.

Второй блок узкий и высокий, под вертикальное видео про Приорат. Видео заполняет блок целиком,
лишнее по краям обрезается. Пока `data-src` пустой, в блоке тёмный фон с редкими пузырьками и подпись «Видео скоро появится».

## Как устроен сайт

- **Первый экран.** Тёмная сцена с бутылкой розового шампанского. При прокрутке пробка вылетает,
  брызги цвета розе заливают экран светлым, а следующий блок уже того же цвета.
  Брызги рисуются в `assets/js/main.js`, без картинок.
- **Пузырьки** редкие и мелкие, поднимаются по краям экрана.
- **Слепая дегустация.** Игра стоит перед проектами: три истории из переговоров видны сразу, у каждой
  четыре бренда на выбор. Если угадали, карточка наливается розе, если нет, красным вином.
  Истории лежат в блоках `<li class="quiz__card">`; у верного варианта `data-right="true"`, пояснение в `data-explain`.
- **Проекты** карточками по четыре в ряд, FMCG первыми. Карточка наклоняется за курсором, по нажатию
  переворачивается в ту сторону, где нажали; на обороте итог и история. Каждый проект — блок `<li class="card">`.
- **Контакты** прямо внутри бокалов: вино наливается, и почта, телефон и Instagram проступают в нём.
  Почту и телефон можно скопировать кнопкой.

Если в настройках устройства включено «Уменьшить движение», анимации выключаются: бутылка стоит закрытой,
бокалы уже налиты, контакты видны сразу. Без JavaScript у карточек видны обе стороны, а в игре под каждой историей есть ответ.
