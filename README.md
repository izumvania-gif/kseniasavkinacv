# Сайт Ксении Савкиной

Личный сайт: статичный HTML, CSS и немного JavaScript, без сборки и фреймворков.
Публикуется через GitHub Pages из ветки `main`.

Адрес после включения Pages: https://izumvania-gif.github.io/kseniasavkinacv/

## Как включить GitHub Pages (один раз)

1. Открой репозиторий на GitHub → **Settings** → **Pages**.
2. В блоке **Build and deployment** выбери **Source: Deploy from a branch**.
3. Ветка **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты сайт появится по адресу выше.

## Как добавить видео

В блоке «Вино и интересы» два слота под вертикальные видео (9:16).

1. Положи файлы в папку `media/`, например `media/grapes.mp4` и `media/priorat.mp4`.
   GitHub принимает файлы до 100 МБ; лучше сжать ролик до 20–40 МБ (H.264, 1080×1920).
2. В `index.html` найди `<figure class="video" data-src="" ...>` и впиши путь:
   - первый слот (сорта винограда): `data-src="media/grapes.mp4"`
   - второй слот (Приорат): `data-src="media/priorat.mp4"`
3. По желанию добавь обложку: картинку в `media/` и путь в `data-poster`.

Пока `data-src` пустой, на месте видео показывается аккуратная заглушка «Видео скоро появится».

## Как устроены проекты

Проекты оформлены как слепая дегустация: на подложке стоят 12 чёрных бокалов с номерами и названиями.
При наведении (на компьютере) или нажатии (на телефоне) стекло светлеет, внутри видно вино,
а лист дегустации заполняется: внешний вид, аромат, вкус и вывод. Имя клиента появляется только в «Выводе».
Красное вино — сделки, белое и розовое — винные проекты.

Каждый бокал — блок `<li class="sample">` в `index.html`: цвет вина задаётся в `style="--w: ..."`,
название цвета — в `data-color`, текст заметки — в списке `<dl>` внутри блока.

## Контакты

Контакты оформлены как контрэтикетка бутылки: почту и телефон можно скопировать кнопкой,
а повод письма («Обсудить проект», «Позвать на встречу», «Поговорить о вине») подставляется в тему письма.
